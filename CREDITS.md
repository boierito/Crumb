# Credits and source provenance

Crumb derives from [WaffleStore](https://github.com/nxtcoreee3/WaffleStore)
by nxtcoreee3, with earlier work from MuffinStore Jailed and PancakeStore.
The original source snapshot is preserved in Git as `upstream-wafflestore-2.2.2`
(commit `d508e53`); the older upstream release name was `WaffleStore2.2.2`.
The original application identity was `com.nxtcoreee3.WaffleStore`.
These are historical attributions, not Crumb's current target, paths or identity.

## iPadN / mengangs and contributors

Crumb integrates code from [iPadN](https://github.com/mengangs/ipadn):
the FairPlayCore C engine, the WebKit/WebAssembly SAP signing runtime,
Apple Store device provisioning/proof handling, and App Group integration
patterns. The SAP port is pinned to upstream commit
`70f2ac36e7f87cacf82a45b58e6fa27ed23ecb80`. iPadN is distributed
under **GPL-2.0-or-later**. See `third_party/iPadN-GPL-2.0.txt` and
`THIRD_PARTY_NOTICES.md` for source attribution, vendor provenance,
redistribution limitations and other contributors.

See README.md and THIRD_PARTY_NOTICES.md for contributors, licensing and other
