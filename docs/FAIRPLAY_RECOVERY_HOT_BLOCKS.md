# Recovery hot blocks

An isolated local replay using the owner's original IPA and pre-authorization
capture counted generic instructions by public start PC. Five blocks accounted
for 13,569,174 of 13,768,031 interpreted instructions before the first memory
fault. The largest block alone accounted for 10,467,072. This measurement is
specific to that execution: the later, authorized state exists only on the
phone and might take different paths. No private inputs were sent to Actions.

Translate those five complete basic blocks from the exact pinned public daemon
ahead of time. Their instruction bytes are checked against the verified image;
unsupported PCs continue to use the generic interpreter. The existing native
region block limit and generic instruction limit remain enforced, and no
validation is bypassed. Moving instructions into AOT blocks changes which limit
accounts for that work and is not a proof that the full recovery terminates.

The candidate generator ran in Actions 40601724734. Sixty deterministic public
synthetic machine states compare all registers, flags, full touched memory pages
and branch destinations against Unicorn, using the existing portable branch
convention for BRAA; this does not prove native pointer authentication. The
existing broad AOT-versus-generic comparison remains part of portable CI.
No real candidate has been validated against the SINF by these synthetic tests.
